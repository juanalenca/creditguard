Slide 6: Tratamento e Preparação dos Dados
Título: Tratamento e Preparação dos Dados
Fluxo de Dados:
Arquivos cobranca_assessorias.csv e fluxo_pagamentos.xlsx passam por extração, transformação, limpeza, validação, geração de arquivos limpos e carga no PostgreSQL.
Bases Utilizadas:
Cobranças de assessorias (.csv)
Fluxos de pagamentos (.xlsx)
Volume de Dados:
10.000 contratos financeiros
100.000 registros de pagamentos
Processo ETL:
Correção de encoding
Padronização textual
Tratamento monetário
Conversão e normalização de datas
Imputação de scores nulos pela mediana
Tratamento de 80 outliers de atraso (-999 e 9999 dias), substituídos pela mediana válida de 89 dias
Integração entre contratos e pagamentos
Resultado:
Base consolidada sem outliers operacionais, pronta para geração de KPIs, dashboards e insights.
Identificação: Equipe Linus. Apresentador: Ruan Deud. Slide 6 de 14.

Slide 8: Arquitetura Integrada da Plataforma
Título: Arquitetura Integrada da Plataforma
Fluxo Arquitetural:
Datasets (CSV / XLSX) -> Python + Pandas (ETL Pipeline) -> PostgreSQL (Supabase Cloud)
PostgreSQL -> API Node.js Express REST -> React Web (Dashboard Executivo)
Processamento e Armazenamento:
Consolidação por lote através de scripts Python, geração de seed_real.sql e carga no PostgreSQL.
APIs & Interface de Decisão:
Serviços web consomem consultas SQL analíticas e entregam respostas JSON para React, Recharts e módulos operacionais.
Governança:
KPIs documentados, regras heurísticas auditáveis e dados tratados sem outliers de atraso.
Identificação: Equipe Linus. Apresentador: Matheus Henrique. Slide 8 de 14.

Slide 9: Persistência e Processamento Analítico
Título: Persistência e Processamento Analítico
Fluxo Backend e Banco:
Banco PostgreSQL no Supabase contendo tabelas principais, mapeado por consultas SQL para uma API Node.js Express, que fornece respostas em JSON para o dashboard React.
Tabelas Principais:
Contratos
Pagamentos
Usuários
Alertas de risco
Modelagem Física / Atributos:
CONTRATOS: id_contrato, nome_assessoria, dias_atraso_inicial, valor_inadimplente, status_cobranca, score_risco, regiao.
PAGAMENTOS: id_pagamento, id_contrato, data_vencimento, data_pagamento, valor_parcela, valor_pago.
ALERTAS_RISCO: id_alerta, id_contrato, nivel_risco, descricao, criado_em.
USUARIOS: id_usuario, nome, email, senha_hash.
Endpoints Principais:
/api/kpis
/api/kpis/avancados
/api/insights
/api/alertas
/api/clientes
/api/dashboard/evolucao
/api/dashboard/risco-regional
Consultas Analíticas:
SUM(), COUNT(), AVG(), GROUP BY e COALESCE() para consolidação de métricas.
